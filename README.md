# Personal Portfolio

Static portfolio site for GitHub Pages. Plain HTML, CSS and JS. No build step.

## Deploy
1. Create a public repo named `<username>.github.io`.
2. Upload every file in this folder to the repo root (Add file > Upload files) and commit.
3. Settings > Pages > Source: Deploy from a branch > `main` / `(root)` > Save.
4. Wait 1 to 5 minutes. Your site is at `https://<username>.github.io`.

## Customize
- All text is in `index.html`. Search for "Your Name" and replace the placeholders.
- Colors are variables at the top of `style.css` (navy and silver).
- Put images and your CV PDF in `assets/`.
